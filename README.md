# Brhanu Atsbaha — Portfolio

Personal portfolio of Brhanu Atsbaha, Data & AI Engineer in Berlin.

**Live:** https://brhanu-atsbaha.vercel.app

## Stack

- A single static `index.html` — hand-written HTML, CSS and vanilla JavaScript, no build step or framework
- Fonts: Fraunces, Inter and JetBrains Mono (Google Fonts)
- Hosted on Vercel; every push to `main` deploys to production

## Sections

Profile · Research & ML (M.Sc. thesis, SimKD, B.Sc. project) · Toolkit · Career timeline · Education · Contact

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Editing

All content lives in `index.html`. Edit the text there, commit, and push to `main`; Vercel redeploys automatically.
